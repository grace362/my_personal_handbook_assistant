Northline Analytics demo corpus — exactly three company handbooks:

  people_handbook.txt      — Employee handbook (time off, pay, conduct)
  it_security_policy.txt   — IT & security policy
  operations_guide.txt     — Operations (purchasing, travel, customer support)

Rebuild the index after edits:

  python reindex_corpus.py

Optional uploads via the UI are not included when you reindex (programme folder only).
